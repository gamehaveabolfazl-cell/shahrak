# شهرک زندگی | Shahrak Zendegi

وب‌سایت معرفی پروژه «شهرک زندگی» و موتور اختصاصی Shahrak Engine.

## انتشار با GitHub Pages
1. وارد بخش **Settings** مخزن شوید.
2. از منوی کناری **Pages** را باز کنید.
3. در قسمت **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و **Save** کنید.
5. پس از پایان انتشار، سایت از این نشانی در دسترس خواهد بود:
   https://gamehaveabolfazl-cell.github.io/shahrak/

## نکته امنیتی مهم
بخش ورود مدیریت در نسخه فعلی فقط نمایشی است و هر نام کاربری و رمز غیرخالی را می‌پذیرد. این صفحه احراز هویت واقعی ندارد و نباید برای حفاظت از اطلاعات یا مدیریت عمومی استفاده شود. برای پنل واقعی به سرور، پایگاه داده، احراز هویت امن و کنترل دسترسی نیاز است.

## وضعیت محتوا
این مخزن فعلاً فقط وب‌سایت معرفی را نگه می‌دارد. فایل‌های بازی و موتور بدون تأیید جداگانه اضافه یا تغییر داده نمی‌شوند.
